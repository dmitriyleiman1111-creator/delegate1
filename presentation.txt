СЛАЙД 1: Введение в проект «Календарь мероприятий КузГТУ»

Проект «Календарь мероприятий КузГТУ» представляет собой современное веб-приложение, разработанное специально для учебного заведения КузГТУ. Основная цель проекта — централизованное управление и отображение всех мероприятий университета в удобном цифровом формате. Приложение позволяет студентам, преподавателям и сотрудникам легко просматривать предстоящие события, узнавать даты, время и места проведения различных активностей. Система поддерживает полный цикл управления мероприятиями: создание новых записей, редактирование существующих и удаление устаревших данных. Особое внимание уделено пользовательскому опыту — интерфейс интуитивно понятен даже новичкам. Проект решает актуальную проблему информационной разрозненности, предоставляя единую платформу для публикации событий университетской жизни.


СЛАЙД 2: Используемые технологии проекта

В основе проекта лежит мощный стек технологий современной веб-разработки. Backend реализован на языке программирования Python версии 3.8 или выше с использованием микрофреймворка Flask, который обеспечивает лёгкость и гибкость разработки. Для работы с базой данных применяется ORM-библиотека Flask-SQLAlchemy, позволяющая взаимодействовать с данными через объектно-ориентированный подход. В качестве системы управления базами данных выбрана SQLite — лёгкая файловая СУБД, не требующая отдельной настройки сервера. Frontend выполнен на чистых HTML5 и CSS3 без внешних зависимостей, что гарантирует быструю загрузку страниц. Шаблонизатор Jinja2, встроенный во Flask, используется для динамической генерации HTML-страниц. Такой технологический выбор обеспечивает простоту развёртывания, минимальные требования к серверным ресурсам и лёгкость поддержки кода.


СЛАЙД 3: Архитектура и структура проекта

Проект имеет классическую трёхуровневую архитектуру веб-приложения. Основной файл app.py содержит всю бизнес-логику: определение модели данных Event, маршрутизацию запросов и обработку форм. Модель Event включает поля: идентификатор, название, описание, дата мероприятия, время, место проведения и дата создания записи. Папка templates хранит три HTML-шаблона: index.html для отображения календаря, add_event.html для добавления событий и edit_event.html для их редактирования. Статические файлы, включая таблицу стилей style.css, размещены в папке static. База данных events.db автоматически создаётся в папке instance при первом запуске. Приложение следует паттерну MVC (Model-View-Controller), где модель представлена классом Event, представление — HTML-шаблонами, а контроллер — функциями маршрутов во Flask. Такая структура обеспечивает чёткое разделение ответственности между компонентами.


СЛАЙД 4: Функциональные возможности системы

Система предоставляет пользователям широкий спектр функций для эффективного управления мероприятиями. На главной странице все события отображаются в виде карточек, отсортированных по дате и времени проведения. Прошедшие мероприятия визуально выделяются для удобства навигации. Пользователь может добавить новое мероприятие, указав обязательные параметры — название и дату, а также опциональные — время, место и подробное описание. Редактирование позволяет обновить любую информацию о существующем событии через удобную форму. Функция удаления включает подтверждение действия для предотвращения случайных ошибок. Система flash-сообщений информирует пользователя об успешном выполнении операций или возникших ошибках валидации форм. Адаптивный дизайн обеспечивает корректное отображение интерфейса на любых устройствах — от настольных компьютеров до мобильных телефонов, что критически важно для доступности информации.


СЛАЙД 5: Обоснование выбора решений и перспективы развития

Выбор технологий обусловлен требованиями к простоте развёртывания в учебной среде и минимальными затратами на поддержку. Flask выбран за свою лёгкость и отсутствие избыточной сложности, характерной для крупных фреймворков. SQLite не требует администрирования базы данных, что идеально подходит для небольших проектов образовательного учреждения. Отсутствие JavaScript-зависимостей уменьшает поверхность атаки и ускоряет работу приложения. Цветовая схема использует фирменные цвета КузГТУ — тёмно-синий (#061A44) для шапки и светлые тона для контента, создавая узнаваемый корпоративный стиль. Проект масштабируем: при необходимости можно добавить систему авторизации, экспорт мероприятий в календари, интеграцию с социальными сетями университета или расширить функционал категориями событий. Текущая реализация служит надёжной основой для дальнейшего развития цифровой экосистемы КузГТУ, демонстрируя практическое применение навыков веб-разработки для решения реальных задач учебного заведения.
