# Календарь мероприятий на Python (Flask)

Веб-приложение для управления календарём мероприятий, созданное на Python с использованием фреймворка Flask.

## 🚀 Возможности

- ✅ Просмотр всех мероприятий в виде карточек
- ✅ Добавление новых мероприятий с указанием:
  - Названия
  - Даты (обязательно)
  - Времени (опционально)
  - Места проведения
  - Описания
- ✅ Редактирование существующих мероприятий
- ✅ Удаление мероприятий
- ✅ Адаптивный дизайн с приятным градиентным фоном
- ✅ Подсветка прошедших мероприятий
- ✅ Flash-сообщения об успешных операциях и ошибках

## 📋 Требования

- Python 3.8+
- Flask
- Flask-SQLAlchemy

## 🛠️ Установка

1. Установите зависимости:
```bash
pip install flask flask-sqlalchemy
```

2. Запустите приложение:
```bash
python app.py
```

3. Откройте браузер и перейдите по адресу:
```
http://localhost:5000
```

## 📁 Структура проекта

```
/workspace/
├── app.py                 # Основной файл приложения
├── templates/             # HTML-шаблоны
│   ├── index.html         # Главная страница (календарь)
│   ├── add_event.html     # Форма добавления мероприятия
│   └── edit_event.html    # Форма редактирования мероприятия
├── instance/              # Папка с базой данных (создаётся автоматически)
│   └── events.db          # SQLite база данных
└── README.md              # Этот файл
```

## 💡 Использование

1. **Главная страница** - отображает все мероприятия в виде карточек, отсортированных по дате
2. **Добавить мероприятие** - нажмите кнопку "+ Добавить мероприятие" и заполните форму
3. **Редактировать** - нажмите "✏️ Изменить" на карточке мероприятия
4. **Удалить** - нажмите "🗑️ Удалить" и подтвердите действие

## 🔧 Настройка

В файле `app.py` вы можете изменить:
- `SECRET_KEY` - секретный ключ для сессий
- `SQLALCHEMY_DATABASE_URI` - путь к базе данных
- `port` - порт сервера (по умолчанию 5000)

## 📝 Технологии

- **Backend**: Python 3, Flask, Flask-SQLAlchemy
- **Database**: SQLite
- **Frontend**: HTML5, CSS3 (без внешних зависимостей)
- **Template Engine**: Jinja2

## 🎨 Дизайн

Приложение использует современный градиентный дизайн с адаптивной вёрсткой, которая хорошо смотрится как на десктопе, так и на мобильных устройствах.
